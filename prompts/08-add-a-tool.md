# Add a tool

*When:* You started using a new app (platform, calendar, news) and want the assistant to use it.

Copy everything in the box below into Claude.

````text
Run the ADD_TOOL flow from CLAUDE.md for: <the app I use>.
Check whether Claude has a connector for it, and if not, the best second option
(an export, a calendar file, or web search). Show me the options with links, let me pick,
then walk me through it one step at a time and update config/profile.json.
````
